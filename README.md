# BimaLift

BimaLift is an offline workout tracker for Android. Set up a repeating training split, such as Chest, Back, and Legs, and the app walks you through each day. Log every set during a session, get a rest timer between sets, and review your history and volume progress over time.

Everything is stored on your device. There is no account, no analytics, and no advertising.

## Features

- Workout categories with exercises, target sets, reps, and weight, including reps-only moves
- A rotation that cycles through your training days
- A dashboard with a Start button for each day and a checkmark once it's done
- A live session with a global timer, expandable exercises, checkable sets, and a rest timer
- Exercise library with search by name, muscle, or equipment, and support for your own exercises with photos
- History with session logs and volume progression charts
- Backup to a Google Drive folder you control, or export and import as a file

## Optional integrations

- **Google Drive backup** uses Google Sign-In and the `drive.file` scope, so the app can only access files it creates.
- **Huawei Health** shows heart rate and calories during a session. It is read-only, and the readings are not saved. This integration is on the `huawei` branch only.
